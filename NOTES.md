# NOTES

Cross-owner requests and integration notes. To keep parallel branches free of merge conflicts,
each agent writes its own file in `notes/`:

- `notes/agent-a.md` (data engine)
- `notes/agent-b.md` (upload + mapping UI)
- `notes/agent-c.md` (outputs + export)
- `notes/agent-d.md` (templates)
- `notes/agent-e.md` (shell + polish)

Write: what you need changed in someone else's file or in `CONTRACTS.md`, why, and how you worked
around it for now. Also list assumptions you made and anything you deliberately skipped.
